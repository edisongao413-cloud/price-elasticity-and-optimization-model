# Price Elasticity & Profit Optimization Model


## Project Overview
This project analyzes product-level sales and pricing data to estimate price elasticity and evaluate profit-maximizing pricing strategies.


## Tools
- Python
- pandas
- scikit-learn
- NumPy
- Power BI


## Analysis
- Cleaned and analyzed six months of sales and pricing data
- Estimated demand sensitivity across five products
- Compared three pricing strategies
- Evaluated product-level profit outcomes


## Key Result
The optimized pricing strategy produced a projected 34.4% increase in net profit compared with the baseline scenario.
